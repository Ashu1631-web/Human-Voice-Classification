## 📌 Project Overview

This project analyzes human voice audio and extracts meaningful features such as:

- Spectral Features  
- Pitch Features  
- MFCC (Mel Frequency Cepstral Coefficients)  

Using these features, a trained ML model predicts whether the voice belongs to a **Male or Female speaker**.

---

## 🎯 Features

✔ Upload audio file (.wav / .mp3)  
✔ Automatic feature extraction using Librosa  
✔ Gender prediction (Male / Female / Uncertain)  
✔ Confidence score display  
✔ Interactive UI with Streamlit  
✔ Clean and responsive dashboard
